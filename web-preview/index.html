      Manual Continuous Deployment (.github/workflows/deploy.yml)

      Trigger deployments on demand from GitHub Actions → Manual CD — Deploy to Chrome & Firefox Stores → Run workflow. Choose store target (all, chrome, firefox), optional semver bump (none, patch, minor, major), and dry_run mode.

      Required Repository Secrets

      Secret Store Purpose
      CHROME_EXTENSION_IDChrome Web Store32-character extension ID from Chrome Developer Dashboard
      CHROME_CLIENT_IDChrome Web StoreGoogle Cloud OAuth2 Client ID for Chrome Web Store API
      CHROME_CLIENT_SECRETChrome Web StoreGoogle Cloud OAuth2 Client Secret
      CHROME_REFRESH_TOKENChrome Web StoreOAuth2 Refresh Token with chromewebstore scope
      AMO_JWT_ISSUERFirefox AMOMozilla Add-ons API JWT Issuer (user:...)
      AMO_JWT_SECRETFirefox AMOMozilla Add-ons API JWT Secret
      TWITCH_SECRETShared (optional)Twitch Client Secret (only if switching to OAuth code flow)

      Workflow Pipeline Stages

      1. build_and_validate  -> npm ci -> optional semver bump -> build Chrome & Firefox MV3
                       -> ESLint + Chrome MV3 validator + Firefox web-ext lint
                       -> package Chrome .zip, Firefox .zip & Mozilla source .zip
2. deploy_chrome       -> scripts/publish-chrome.js (Chrome Web Store API v1.1 upload + publish)
3. deploy_firefox      -> web-ext sign --channel=listed --upload-source-code source.zip
4. github_release      -> Create GitHub Release vX.Y.Z with all store & source archives attached
